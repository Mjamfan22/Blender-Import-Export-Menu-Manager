# Contributing

Thanks for helping improve BM Import & Export Menu Manager.

## Bug reports

Please include:

- Blender version and operating system;
- add-on version;
- clear reproduction steps;
- the expected and actual result;
- relevant screenshots or console errors; and
- names of other import/export add-ons involved.

## Pull requests

1. Keep changes focused and preserve existing user preferences.
2. Do not unregister or replace third-party import/export operators.
3. Update documentation and changelog entries for user-visible changes.
4. Run `python tools/validate.py` before submitting.
5. Test menu restoration by disabling the manager and the add-on.
