# Changelog

All notable changes are documented here. This project follows semantic
versioning.

## [1.1.2] — 2026-10-26

- Collapsed each preference entry into one compact horizontal row.
- Kept the dotted press-hold-drag handle, visibility, label, operator ID,
  group assignment, and fallback arrows together.
- Recalibrated drag movement for the compact row height.
- Added public project, maintainer, and support metadata.
- Made release ZIP generation byte-for-byte reproducible across operating
  systems and added automated checksum verification.

## [1.1.1] — 2026-10-26

- Replaced click-to-grab placement with dotted press-and-hold drag handles.
- Added multi-row vertical dragging for entries and groups.
- Fixed release-state cleanup so repeated drags remain reliable.
- Prevented ambiguous entry reordering while a text filter is active.

## [1.1.0] — 2026-10-26

- Added rapid grip-based reordering and lossless cancellation.
- Added accessible one-step arrow controls.

## [1.0.1] — 2026-10-25

- Improved dynamic enum safety and third-party menu diagnostics.
- Expanded operator enums into independently configurable entries.

## [1.0.0] — 2026-10-25

- Initial Blender 5.2 LTS release.
- Added independent visibility, labels, groups, and order for Import and Export.
