# Security policy

## Supported version

Security fixes are applied to the latest published release.

## Reporting a vulnerability

Do not include sensitive details in a public issue. Use GitHub's private
security advisory feature for this repository when available. Include the
affected version, reproduction steps, potential impact, and any suggested
mitigation.

This add-on operates entirely inside Blender and does not make network
requests, collect telemetry, or transmit project files.
